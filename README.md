## 🏗️ **Projetos em Destaque**

* **🔗 [API de Controle Financeiro Empresarial](https://github.com/eduardoferreiralima/ProfitFlow)**
  * *Tech Stack:* Java, Spring Boot, Spring Security, PostgreSQL.
  * *Foco:* Controle de fluxo de caixa corporativo, segurança em nível de endpoint e relatórios estruturados de transações.

* **🔗 [API de Gestão e Controle de Turmas](https://github.com/Integrador-Coorporativos/academic_service)**
  * *Tech Stack:* Java, Spring Data JPA, Hibernate, PostgreSQL.
  * *Foco:* Mapeamento e modelagem relacional complexa de relacionamentos muitos-para-muitos (N:M) entre alunos, professores e turmas.

* **🔗 [API de Processamento de Planilhas](https://github.com/Integrador-Coorporativos/import_and_report_service)**
  * *Tech Stack:* Java, Spring Boot, Spring Validation.
  * *Foco:* Arquitetura focada em validação estrita de dados de entrada, tratamento global de exceções customizadas e cálculo automatizado de métricas de desempenho.
